YouTube integration

Owner-controlled private publishing.

AutoTech Lab uses Google's OAuth 2.0 authorization and the YouTube Data API to upload video files to a YouTube channel controlled by the project owner.

Permission requested

youtube.upload — the permission necessary to upload videos to the authorized YouTube account.

Upload visibility

Videos are submitted with their YouTube visibility set to Private. There is no public sign-in service on this website.

This website provides project information only. It does not perform OAuth sign-in, ask visitors for passwords, or collect YouTube credentials.
