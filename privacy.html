Privacy policy

This policy explains how AutoTech Lab's owner-operated video publishing automation uses Google authorization and YouTube services.

Last updated: November 10, 2026

AutoTech Lab is an independent educational project. This website is informational only; visitors do not need a Google account or YouTube sign-in to browse it.

1. What the application does

AutoTech Lab creates educational video files and uses the YouTube Data API to upload those files to a YouTube channel authorized by the project owner. The workflow submits videos with Private visibility. It is not a general-purpose public uploader or a service for unrelated users.

2. Google information and permissions accessed

The workflow requests the Google OAuth scope https://www.googleapis.com/auth/youtube.upload. This authorization lets the workflow upload videos to the channel associated with the consenting Google/YouTube account. The project uses the granted authorization to upload the produced video file, its title, and its description, and to obtain an upload result (including a video identifier).

The website itself does not request Google login, ask for passwords, read private emails, access Google Drive, or collect visitors' YouTube account information. If the workflow's permissions change in the future, this policy must be updated before that change is used.

3. How authorization and data are used

  • Google OAuth credentials are used solely to authorize YouTube uploads for the project owner.
  • Generated narration, video files, episode titles, and descriptions are processed in the project's automated production workflow.
  • The video ID and upload status may be recorded in the project's private repository to prevent duplicate uploads and support troubleshooting.
  • OAuth authorization is not used for advertising, profiling, or selling user data.

4. Storage, security, and sharing

OAuth client credentials and refresh tokens are configured as access-controlled GitHub Actions secrets for the private production repository. They are not intentionally embedded in the public website or committed into publicly accessible source files. Production files and diagnostic information may be processed on GitHub Actions runners; authorized video metadata and video content are transmitted to YouTube for upload.

Google and GitHub process information in connection with their services under their own terms and privacy policies. The project does not sell Google user data or provide OAuth credentials to advertisers or unrelated third parties. Access to private automation data should be limited to authorized maintainers.

5. Retention and deletion

OAuth secrets are retained in the project's GitHub configuration until replaced or deleted by an authorized maintainer. Upload status and video identifiers may be retained in private repository history to protect against duplicate uploads. Temporary production files and workflow logs follow the applicable GitHub Actions artifact and retention configuration. Uploaded videos remain in the channel until removed by the channel owner under YouTube's controls.

The account owner can revoke the app's Google account authorization from Google Account → Third-party access and can delete or replace stored GitHub Actions secrets. Revoking authorization prevents future authorized uploads; it does not automatically remove videos already uploaded.

6. Website visitors

This static website does not include application sign-in forms, tracking scripts, or advertising pixels in its source. As the site is hosted by a third-party provider, that hosting provider may process ordinary technical information needed to serve pages, such as IP addresses and request logs, under its own privacy practices.

7. Limited use and changes

Google API data obtained through authorization is used only to provide or improve the described YouTube upload functionality, with appropriate access controls. It is not used for unrelated purposes. This policy may be revised if the integration or data practices change; the updated date above will be changed accordingly.

8. Contact

For questions about the project's data practices, contact the project maintainer through the maintainer's GitHub profile. The Google OAuth consent screen also provides the project's designated support contact.
